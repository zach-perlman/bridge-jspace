`probe_swap.json` is the 90 two-hop prompts of the probe-swap experiment in Gurnee et al. (2026),
[Verbalizable Representations Form a Global Workspace in Language Models](https://transformer-circuits.pub/2026/workspace/index.html).
It is copied unchanged.

`lens_eval_multihop.json` is the paper's lens-quality eval for two-hop prompts (93 items: `prompt`, `target`,
`intermediates`; readout at the token before `target`, pass@k over min-over-layers rank). Copied unchanged.

`natural_read_v1/items.json` holds Wikipedia paragraphs, questions and answers from SQuAD v1.1 (Rajpurkar et al. 2016, [SQuAD: 100,000+ Questions for Machine Comprehension of Text](https://arxiv.org/abs/1606.05250)), dev set, distributed under CC BY-SA 4.0 (the site's download note; the site repository's code is MIT). The derived file is under the same licence. The raw file is the one at the pinned commit above; the site's own copy (https://rajpurkar.github.io/SQuAD-explorer/dataset/dev-v1.1.json) had the same sha256 on 2026-10-23. `tests/test_pins.py` rebuilds the items from the raw file when it is cached.

The `tasks_v2/` sets marked CC BY-SA 3.0 use sentences of WikiText-103 test (Merity et al. 2016, [Pointer Sentinel Mixture Models](https://arxiv.org/abs/1609.07843); `wikitext103_test.json` above) as filler, detokenised by their builders; they are under the same licence. The sets marked "built by us" hold no third-party text: their facts, names, filler and templates are written in their builders.

Models and lenses (J-lens, J++) are not stored here; they are downloaded at pinned revisions (see
`configs/models/*.yaml`).

What checks each sha256 listed above:

- A constant in `src/bridge_jspace/pins.py`, compared by `pins.load_pinned_items` when code loads the file through `pins` (a few analysis scripts read some of these files directly, unchecked): `probe_swap.json`, `brew_intermediates.json`, `brew_fresh.json`, `brew_fit.json`, `brew_test.json`, `bind_recall.json`, `bind_lookup.json`, `bind_lookup_v2.json`, `recall_lookup.json`, `lens_eval_multihop.json`, `wikitext103_test.json`, `natural_read_v1/items.json`.
- A constant in `scripts/paper_ko_decomp.py`, asserted when that script loads the file: `lens_eval_multilingual.json`, `lens_eval_order_ops.json`, `lens_eval_poetry.json` (and `lens_eval_multihop.json`).
- Raw inputs, asserted when the file is rebuilt: the SQuAD dev file (`pins.SQUAD_DEV_SHA256`, by `scripts/natural_read.py` and, when it is cached, `tests/test_pins.py`) and `TwoHopFact.csv` (by `scripts/sd_build.py facts`).
- A run manifest: the `suite_v1*` files, asserted against the run's `manifest.json` by `scripts/suite_v1.py` before a competence run.
- A test: `full_v8`'s sha256 in `tasks_v2/full_v8_two/manifest.json` (`tests/test_full_v8_two.py`).
- Nothing; the hash is recorded only: `wsb_wrong_bridge.json`, the WikiText parquet's sha256 (in `wikitext103_test.json`'s `meta`), silent-dissent's `entity_facts.py` (in `sd_v1/manifest.json`), and the parts' hashes in each merged set's `merged_from`.

Rows with "-" in the sha256 column are pinned by the git commit only.
