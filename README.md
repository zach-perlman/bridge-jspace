# bridge-jspace

When a model answers a two-step question, does it use the part of the in-between (bridge) entity that a J-lens can read? This repository holds two reports on that question, each built from its own run files and unverified until hand-checked: the depth report, [The lookup goes around the lens](docs/depth/README.md) (Dan: what a model reads from the bridge word, on four models; built by `scripts/readme_build.py` from `docs/README.template.md`), and the breadth report, [Recall goes through the lens](docs/breadth/README.md) (Zach: what a model needs from the bridge's mention, across models; built by `scripts/report_breadth.py`). Code is in `scripts/` and `src/`, raw runs in `results/`, figures in `figures/`; [DEVELOPER.md](DEVELOPER.md) has the layout and commands and [AGENTS.md](AGENTS.md) the rules for running experiments.
