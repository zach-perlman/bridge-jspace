### 3.2 v2: statement order or token position? A pointer to the answer itself?

**What we do.** Same patching as the first night (copy the alt prompt's hidden states after the question into the org
prompt, layer by layer). Every scene now has one filler sentence, and it sits in a different place in the org and the
alt prompt, so "the 5th statement" and "the same token position" point at different statements. Also run on the
Python code and the foreign-statement scenes.

**Example.** Org prompt: "The oxygen card is in locker 0. The helium card is in locker 9. The lithium card is in
locker 7. *[filler sentence]* The hydrogen card is in locker 3. The carbon card is in locker 4. Which locker holds the
card for the gas fires need?" → answer org 0 (oxygen). Alt prompt: the same cards reordered, the filler at the end,
asking for the party balloon gas (helium), its 5th statement, answer alt 5.

| If the copied state carries... | the org prompt answers |
|---|---|
| the word "helium" | 9 |
| "the 5th statement" (order) | 4 |
| "this token position" | 3 |
| the answer as content | 5 |
| nothing | 0 (answer org kept) |

Reflexive variant: the alt prompt's answer is a digit the org prompt also has (here helium's would be 3), to see
whether the model points at that digit's place rather than carrying the digit.

**Why we care.** "A pointer to a statement" is a claim only if it is the statement's order, not a fixed token
position. A pointer to the answer token itself would be a third route (seen in other work for middle statements).

### 3.3 A learned "pointer" direction (D3b)

**What we do.** From many prompts (a separate fit set), take the hidden states after the question at layers 40-52,
labelled by which statement (1-5) the question asks about, and learn a direction for "the question asks about
statement j" (difference of class means, and small subspaces). Then on new scenes push "statement j minus the
current statement" and see whether the model answers with statement j's digit.

**Example.** "The spider's locker is 1. The cow's locker is 6. The mouse's locker is 9. The goose's locker is 5. The
sheep's locker is 7. Which locker belongs to the animal known for spinning webs?" → answer org 1 (statement 1).
Push "statement 4 minus statement 1" at layer 48:

| Hypothesis | Predicted answer |
|---|---|
| a slot pointer: the learned direction steers | 5 (the goose, 4th statement here) |
| no linear slot code | 1 (answer org kept) |
| the lens push instead (bridge alt = cow) | 6 (the cow's locker here) |
| the alt-prompt patch (reference) | 3 (the alt prompt's own answer) |

Controls: a random push and a shuffled-label direction of the same size; memory → memory items, where a slot
pointer should do nothing; the direction split into the part along real activation differences and the remainder.

**Why we care.** If a learned slot direction steers the lookup where the lens cannot, it is the start of a second,
"pointer" readout next to the J-lens; its angle to the lens's word directions says how separate the two codes are.
