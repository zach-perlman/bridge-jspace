## 1. D3 v2: a pointer to a statement, or to a token position? And a pointer to the answer itself?

**What we do.** Same patching as the first night (paste the alt prompt's hidden states after the question, layer by
layer), on new scenes built so that more hypotheses give different digits.

**Example (offset shift).** A filler sentence sits *before* statement 2 in the org prompt and *after* it in the alt
prompt, so "the 2nd statement" and "the statement at token 40" are different statements.

| If the pasted state carries... | the org prompt answers |
|---|---|
| the alt prompt's statement **order** (2nd statement) | the digit of the org prompt's 2nd statement |
| the alt prompt's **token position** | the digit of the org statement at that token position |
| the **animal** (word) | the org prompt's digit for bridge alt |
| the alt prompt's **answer digit** as content | that digit (absent from the org prompt) |
| a **pointer to the answer token** (alt answer also appears in the org prompt) | the digit at that answer's place in the org prompt |
| nothing | answer org |

**Why we care.** "Pointer to a statement" is a claim only if it is the order, not a fixed token offset. A pointer to
the answer token itself would be a third, different route (seen in other work for middle statements).

## 2. D3b: a "pointer" direction that steers the lookup

**What we do.** From many prompts, take the hidden states after the question at layers 40-52 and learn a direction
for "the asked statement is slot j" (difference of means, and a small subspace). Then on new prompts push along
"slot j minus the current slot" and see whether the answer becomes the digit at slot j.

**Example.** Org prompt asks about the cow, stated 2nd (answer org 5). Push "slot 4 − slot 2" → if the pointer
direction is real, the answer becomes the digit of the 4th statement (say 9), whatever animal is there.

| Push (same size) | Expected if the pointer is real |
|---|---|
| slot direction | digit at the target slot |
| lens push (bridge alt − bridge org) | nothing (as on the first night) |
| random direction | nothing |
| the slot direction on memory → memory | nothing (no lookup) |

**Why we care.** If a learned slot direction steers the lookup where the lens cannot, it is the start of a second,
"pointer" readout next to the J-lens. Its angle to the lens's word directions says how separate the two codes are.
