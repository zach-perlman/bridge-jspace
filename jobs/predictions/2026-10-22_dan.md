## Words used below

| Word | Meaning |
|---|---|
| **memory → prompt** | The animal is recalled from a clue, then its locker is looked up in the prompt. "Which locker belongs to the animal known for oinking?" (pig, then the table) |
| **named → prompt** | The animal is named in the question, then looked up. "Which locker belongs to the pig?" |
| **memory → memory** | Both steps from memory, no table needed. "How many legs does the animal known for oinking have?" (control) |
| **last tokens** | The 1-2 tokens right before the answer ("Answer:") |
| **question words** | The words of the question itself ("Which locker belongs to ... oinking?") |
| **hide X from Y** | Forbid tokens Y to look at sentence X through attention (in the chosen layers only) |
| **% keeping the answer** | Share of items where the model still gives its original, correct answer. High = hiding did not matter there. Low = the model needed that sentence there |
| **org / alt** | Org = the prompt we run and edit. Alt = the other prompt we copy hidden states from |
| **word / slot / answer** | What a copied state might carry: the animal's word ("pig"), a pointer to a statement ("the 3rd statement"), or the digit itself |
| **attention / DeltaNet layers** | The 27B has 16 normal attention layers (look at every past token) and 48 DeltaNet layers (a compressed running memory) |

## What we learned in the first night (not yet verified)

For memory → prompt:
1. The **last tokens** read the answer's statement themselves, through **attention**, at **layers 48-63**. The question
   words don't need it (D2).
2. At layers 44-50 the last tokens carry **which statement to read** (a slot pointer) more often than **which animal**
   (29% vs 9%); from about layer 52-56 they carry the digit itself (D3).
3. The lens cannot steer the answer at layers 44-52.

This batch asks: **(a)** does this hold beyond animal sentences (Python code, other languages, chemical symbols),
**(b)** what exactly is the pointer, and **(c)** can we steer the lookup with a learned pointer direction.

### 3.2 Is the pointer "the Nth statement", or just "this place in the text"?

In night 1 the copied state often said "read that statement". But "the 5th statement" and "the same place in the
text" were always the same thing. Now one **filler sentence** sits in a different place in org and alt, so they
point at different statements.

**Method (same as night 1):** copy the alt prompt's hidden states after the question into the org prompt, one layer
at a time, and see which answer the org prompt gives.

```

     Which locker holds the card for the gas fires need?               -> 0 (oxygen)
Alt: the same cards in another order, filler at the end;
     asks for the party balloon gas = helium, its 5th statement        -> 5
```

| If the copied state carries... | org answers | why |
|---|---|---|
| the word "helium" | **9** | helium's locker in org |
| "the 5th statement" (order) | **4** | org's 5th statement is carbon |
| "this place in the text" | **3** | because of the filler, that place in org holds hydrogen |
| the digit itself | **5** | the alt answer travelled along |
| nothing | **0** | org keeps its own answer |

**Pointer to the digit itself (Q3.10).** Another possible route: the state says "go to where the digit 3 is written".
Test: make the alt answer a digit that also appears in org, and compare with an alt answer that org doesn't have.
If the switch happens much more often when org has that digit, the model points at the digit's place. If equally

### 3.3 Can a learned "pointer" direction steer the lookup?

**Idea.** If the last tokens carry "read statement j", we can learn a direction for each j and push the model with it.
If it then reads another statement, we have a tool that **steers** the lookup where the J-lens can't: a second,
"pointer" lens.

**How.**
1. On separate prompts, take the hidden states after the question at layers 40-52, labelled by which statement (1-5)
   the question asks about.
2. Learn a direction per statement (difference of class means; also small subspaces).
3. On new prompts, push "statement j minus the current statement" and see which digit the model answers.

```
1 spider 1.  2 cow 6.  3 mouse 9.  4 goose 5.  5 sheep 7.
Which locker belongs to the animal known for spinning webs?           -> 1 (statement 1)
Push "statement 4 minus statement 1" at layer 48:
```

| What happens | Answer |
|---|---|
| the pointer direction steers | **5** (goose, statement 4) |
| no linear pointer code | **1** (unchanged) |
| for comparison: the J-lens push "cow instead of spider" | **6** (cow's locker) |

Controls: a random push and a direction learned on shuffled labels, of the same size; memory → memory items, where a
pointer should change nothing.
