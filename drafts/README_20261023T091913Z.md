# bridge-jspace

**The question.** To answer a two-step question, a model first finds an entity in between (the **bridge**), then uses it to get the answer. A **J-lens** reads a model's hidden states as words. Does the model use the bridge in the form the lens reads, or by another route? Example: "Which locker belongs to the animal known for oinking?" → bridge *pig* → answer: the pig's locker number, stated in the prompt (a **lookup**; a **recall** takes the answer from memory). Models: Qwen3.6-27B, Qwen3.5-9B, Olmo-Hybrid-7B, Qwen3.5-122B (hybrids); Qwen3-32B, OLMo-3-7B-I, Muse 30B, Gemma 4 31B-it (attention-only).

## 1. Removing the J-space breaks recall, not the lookup

**How sure:** medium: a control failed on OLMo-3 (animal suite); holds on fewer than three models (27B); holds on hybrids only; holds on a second run on fewer than two models.

**Key evidence:** +36 pts more lost by recall than by the lookup where it holds (weakest: 27B, tasks, Zach's rule: +36 pts, n=506); values only, no committed rule: +9 to +78 pts.

**Models:** holds: Qwen3.6-27B · unclear: OLMo-3-7B-I · values only: Qwen3.5-9B, Qwen3-32B, Muse 30B, Qwen3.5-122B · not testable: Olmo-Hybrid-7B · missing: Gemma 4 31B-it.

_No merged figure for this finding in figures/cross_model/ yet._

**What we did**
- While the bridge forms (the middle layers), removed the J-space (the part of a hidden state the lens reads) and counted the answers still right, for recalls and for lookups; controls: the same removal with the fit rotated, or a random dictionary of the same size.
- Zach's version on his generator's tasks: a knock-out of the lens's top words, judged by his rule (questions answered from memory must lose more than questions answered from the prompt).

**Weak spots**
- OLMo-3, animal suite: not interpretable (the control gate: a control removal keeps < 90% on country-R/clean (rotated 80%), country-R/clean (random 80%)).
- Values only, no committed rule: 27B (animal suite), 9B (animal suite), 32B (animal suite), Muse (animal suite), 122B (animal suite).
- Not testable: Olmo-Hybrid (no lens).
- Not run or no saved verdict: Gemma (not on Zach's branch; blocked).
- The animal-suite removal has no committed rule: its cell shows the gap with an interval chosen after seeing the data (see the choices below).
- Some removal runs dropped the random-dictionary control (too large next to the model on one GPU); their control gate reads the rotated control alone.

**What it means:** Where it holds: a lookup in the prompt does not need the J-space; the other findings ask what it uses instead.

### How sure: the rule

**strong**: holds on three or more models, of both architectures (hybrid and attention-only), on two separate runs (draws, formats, long context) on at least two of them, and no cell of the finding fails, fails a control or is inconclusive · **open**: holds on no model, or fails (or is mixed) on as many models as it holds on · **medium**: everything in between. The reason given is the condition that decided it.

A model's state for a finding, from the verdicts of its cells (every draw and setting, main lens): holds = some cell holds and none fails; fails = some fails and none holds; mixed = both; unclear = only failed controls or the rule's own 'inconclusive'; values only = only cells without a committed rule; not testable = no lens, the gate or competence failed; missing = did not run or no saved verdict.

Rows used: the main lens's (grid.csv's lens column without 'listed beside'), each finding's grid settings; per-topic and per-family breakdown rows are not judged here. Separate runs: separate result folders. Numbers: grid.csv's, rounded half to even.

### Words we use

| Word | Meaning | Example |
|---|---|---|
| **bridge** | The entity found in the first step | "the animal known for oinking" → pig |
| **recall / lookup** | The answer comes from the model's memory / from a sentence in the prompt | how many legs a pig has / "The pig's locker is 3." |
| **J-lens, J-space** | A tool that reads hidden states as words ([Gurnee et al. 2026](https://transformer-circuits.pub/2026/workspace/index.html)); the part of a hidden state it reads; J++ is its refined fit |  |
| **lens push** | Add the lens's direction from one word to another (pig → cow) to a hidden state |  |
| **patch** | Copy hidden states from a donor prompt into the original prompt, at chosen tokens and one layer, and see which answer comes out |  |
| **blocking** | Stop chosen tokens from attending to one sentence, in chosen layers |  |
| **question tokens / last tokens** | The words of the question / the 1-2 tokens right before the answer |  |
| **positive control** | A place where a method is known to work, so that a null result elsewhere means something |  |
| **hybrid / attention-only** | Attention layers mixed with DeltaNet layers (a compressed running memory) / attention in every layer |  |
