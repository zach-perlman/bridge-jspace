Classes: identity the bridge item's own locker digit in S (C1 - the same as original; reported as identity); position the digit in S of the locker sentence at the bridge's sentence slot in O; value the new digit S gives the moved item; original O's answer; other none of these. C0 stores "other" for a correct switch (route_tokens has no "switch"); for C0 the class is re-derived from expect - switch / original / other.; recall switched = the recall follows S (the top token is S's answer, the S pick's legs)

How to read a card
  • Original prompt: what the model reads. Changed prompt: the same scene with the bridge (the asked person's pick) changed; the change is taken from it. Words that differ are highlighted.
  • The change: the difference of the model's hidden state at the bridge word (changed minus original), at the layer shown, added to the original prompt there. The whole change: all of it. Without X: the change minus its X part. Without its random part: minus a random part of the same size (the control). Only X: only the X part added.
  • Original answer: the answer to the original prompt; changed answer: the answer to the changed prompt. The model switches when it gives the changed answer. Lookup: the locker written in the prompt; recall: a fact from memory.
  • P(original answer), P(changed answer): the probability the model gives each answer's first token. Logit gap: logit of the changed answer minus logit of the original; above 0 the changed answer is preferred.
  • What it is: the run's own label for the top token (its code in brackets: A = original answer, b = changed answer). The main test stores no top token, only this label, so "another token" cannot be shown.
  • Extra loss: (switches kept without the random part − switches kept without the part) / switches with the whole change. An item counts only if the whole change switched it.
